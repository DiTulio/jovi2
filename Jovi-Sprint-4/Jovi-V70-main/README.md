## Abrir
Abra index.html no navegador ou siga as instruções do README da raiz. Login demonstrativo: aluno / 1234.

## Importar do Python
Na tela inicial, use Dados do Python → Importar JSON. Selecione o arquivo produzido pela opção 7 de ../Sprint-4-Jovi/jovi.py. O painel mostra usuário, placares individuais, simulados, anotações e pesquisas. É uma cópia para consulta; exporte e importe novamente para atualizar.

O arquivo exemplos/demonstracao.json da raiz contém somente dados fictícios para testar. O painel guarda a última cópia localmente, se o navegador permitir. Remover cópia não altera os dados do Python. A importação substitui a cópia anterior, sem mesclar usuários.

## Arquivos
- index.html, style.css e script.js: interface original e navegação.
- integracao.js: validação de JSON, importação, painel, paginação e armazenamento local.
- integracao.css: estilos da área integrada, seguindo o tema do protótipo.

## Escopo
Câmera IA e bloqueio de apps permanecem simulados. O login web é demonstrativo e independente das contas Python. Atividades do site não são enviadas de volta. Os indicadores demonstrativos originais não são substituídos pelos dados reais, que aparecem na área Dados do Python. O site não executa Python nem possui backend de autenticação.

O código não contém comentários. As instruções estão na documentação. A licença original foi preservada.
